# SQL 101 — School Database Project

## 📌 Project Overview

This project was created as part of the **SQL 101 course on Satr Platform**.

The goal of the project is to build a centralized database for **Excellence Secondary School** to store and manage information about students, teachers, and courses.

## 🏫 Database Structure

The database contains three main tables:

* **Students** — Stores student information such as ID, name, birth date, gender, enrollment date, email, academic level, track, and GPA.
* **Teachers** — Stores teacher information such as ID, name, birth date, gender, email, and office number.
* **Courses** — Stores course information such as course ID and course name.

## 🛠️ SQL Concepts Applied

Throughout this project, I practiced the following SQL concepts:

* Creating a database using `CREATE DATABASE`
* Creating tables using `CREATE TABLE`
* Working with different data types
* Inserting data using `INSERT INTO`
* Retrieving data using `SELECT`
* Displaying available tables
* Sorting data using `ORDER BY`
* Using aliases with `AS`
* Updating existing data using `UPDATE`
* Modifying table structures using `ALTER TABLE`
* Adding comments to explain SQL commands

## 📊 Project Requirements

The project includes:

* A centralized school database
* Student, teacher, and course tables
* 30+ student records
* 10+ teacher records
* 6+ course records
* Data retrieval and sorting
* Column aliases
* Updating student and teacher information
* Renaming a table
